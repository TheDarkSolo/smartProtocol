# Smart Protocol

Конструктор жалоб на постановления о нарушении ПДД в Казахстане.
Пользователь загружает постановление — сервис находит законные основания
для обжалования и готовит документ к подаче.

Видение, архитектурные решения и этапы — в [ROADMAP.md](ROADMAP.md).

## Запуск

Бэкенд:
```bash
cd backend && python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

Фронтенд:
```bash
cd frontend && npm install && npm run dev
```

Фронтенд проксирует `/api` на `localhost:8000`. Лендинг рендерится и без
поднятого бэкенда — на запасных значениях конфигурации.

Telegram-бот (вторичный канал, см. [bot/README.md](bot/README.md)):
```bash
cd bot && python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m app.main
```

## Структура

```
backend/      FastAPI: конфигурация, приём постановления, сборка жалобы
bot/          Telegram-бот (aiogram 3) — вторичный канал, вызывает backend/
knowledge/    Нормы права и основания обжалования (см. предупреждение ниже)
frontend/     React + Vite + TypeScript, ru/kk, mobile-first
.claude/      Агенты проекта и конфигурация запуска
ROADMAP.md    Видение, решения, этапы, риски
```

## Секреты

`backend/.env` и `bot/.env` — реальные ключи, в git не попадают
(`.gitignore`). Шаблоны — `*.env.example` рядом с каждым. Сейчас это ключ
DeepSeek (`SP_DEEPSEEK_API_KEY`, используется для изложения фактов при сборке
жалобы — модель не имеет доступа к базе норм и не может подставить в документ
ссылку на статью, это всегда делает шаблон) и токен Telegram-бота
(`SPBOT_BOT_TOKEN`, получается у @BotFather).

## Что уже есть
- Лендинг: первый экран с загрузкой, «как это работает», основания
  обжалования, цена, вопросы, дисклеймер
- Переключение русский / казахский на сайте и в боте
- Адаптив от 360px, только светлая тема
- `GET /api/config`, `POST /api/cases` с проверкой типа и размера файла
- `POST /api/cases/{case_id}/draft` — черновик жалобы по одному отработанному
  основанию (жёлтый сигнал светофора): шаблон вставляет проверяемые нормы,
  DeepSeek только формулирует изложение фактов пользователя
  (см. [backend/app/services/appeal_draft.py](backend/app/services/appeal_draft.py))
- Telegram-бот: приём постановления файлом/фото через тот же `POST /api/cases`
  (см. [bot/README.md](bot/README.md))

## Чего ещё нет
Разбор постановления, подбор оснований по остальным составам, PDF на выходе,
оплата, напоминания о сроках, полная база норм `knowledge/`. Это этапы 0–2 в
ROADMAP.md.

## Перед первым платящим пользователем
- Заполнить `knowledge/` — статьи, основания, сроки — с подтверждением по
  первоисточнику. Без этого продукт выпускать нельзя.
- Написать оферту и политику обработки персональных данных; ссылки в подвале
  сейчас заглушки.
- Проверить значение МРП в `backend/app/config.py` (`mrp_verified: false`).
- Вычитать казахский перевод носителем языка и юристом.
